# Coding Agent

## Principles the Agent needs to follow

| Principle | Addresses | As spoken to a person |
| --- | --- | --- |
| Think Before Coding | Wrong assumptions, hidden confusion, missing tradeoffs | Understand the requirement, avoid handling unrequested edge cases. |
| Simplicity First | Overcomplication, bloated abstractions | Keep the solution simple, don't plan ahead. |
| Surgical Changes | Orthogonal edits, touching code you shouldn't | Limit the changes or diff size. Fix one issue per commit. |
| Goal-Driven Execution | Leverage through tests-first, verifiable success criteria | Verify the results. |
