# PostmarkOS

## Install

* Install pmbootstrap
* `pmbootstrap init`
* `pmbootstrap install`

## Troubleshooting

* `pmbootstrap update`
* `pmbootstrap -v install`
* Go to the [issues](https://github.com/postmarketOS/pmbootstrap/issues/) page
* `pmbootstrap pkgrel_bump --auto`
* Default Pin: 147147
